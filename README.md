# Prati Birthday Website

A static HTML/CSS/JavaScript birthday website designed to work on desktop and mobile.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, the `assets` folder, and `.nojekyll`.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site.

Keep `index.html` at the repository root.
